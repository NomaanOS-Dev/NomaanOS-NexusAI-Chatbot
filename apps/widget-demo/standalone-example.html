🌐 Standalone Script Embed Showcase

This static HTML page demonstrates embedding the NomaanOS Nexus AI chat widget using a standalone <script> bundle with zero build steps or bundlers required.

HTML Embed Code

<!-- 1. Include Nexus Chat Widget CSS -->
<link rel="stylesheet" href="http://localhost:4001/widget/style.css">

<!-- 2. Include Standalone Script Bundle -->
<script 
  src="http://localhost:4001/widget/nexus-widget.umd.js"
  data-assistant-id="4f9d1462-8321-4f11-8be8-2d83ba32d1e0"
  data-api-base-url="http://localhost:4001"
  data-position="bottom-right"
  async>
</script>

Programmatic Control API

The standalone bundle exposes window.NexusWidget for advanced control:

// Initialize programmatically
window.NexusWidget.init({
  assistantId: '4f9d1462-8321-4f11-8be8-2d83ba32d1e0',
  apiBaseUrl: 'http://localhost:4001',
  position: 'bottom-right'
});

// Destroy / unmount instance
window.NexusWidget.destroy();
